# Звіт про навантажувальне тестування (k6)

## 1. Команда запуску
```bash
k6 run -e TARGET_URL=http://cloud-lab1-alb-1417131122.eu-north-1.elb.amazonaws.com loadtest/script.js
```

## 2. Параметри сценарію тестування
- **Профіль навантаження:** 1 операція запису (`POST /items`) та 9 операцій читання (`GET /items`) у циклі на одного віртуального користувача.
- **Максимальна кількість користувачів (VUs):** 60 VUs.
- **Тривалість та фази:**
  1. **Фаза 1 (Ramp-up):** наростання від 0 до 60 VUs за 2 хвилини.
  2. **Фаза 2 (Steady state):** стале навантаження 60 VUs протягом 5 хвилин.
  3. **Фаза 3 (Ramp-down):** спад від 60 до 0 VUs за 2 хвилини.
- **Загальна тривалість тесту:** 9 хвилин.
